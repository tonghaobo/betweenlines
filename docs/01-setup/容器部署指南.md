# 容器部署指南

> 本文档面向**全新环境**：从零安装 Docker 到项目上线，一条指令都不缺。

---

## 零、Docker 文件说明

以下 Docker 相关文件**已提交 Git**，克隆项目后可直接使用，无需任何额外配置：

| 文件 | 作用 |
|------|------|
| `Dockerfile` | 镜像构建定义（基于 `ubuntu:24.04`，安装 Node.js 20 + Python 3.12） |
| `docker-compose.yml` | 服务编排：环境变量、端口、数据卷 |
| `entrypoint.sh` | 容器启动脚本：生成 `.env` → 启动后端(8000) → 启动前端(3000) |
| `.dockerignore` | 构建排除规则（node_modules / .venv 等不进入镜像） |

---

## 一、安装 Docker（全新环境首次）

### Ubuntu / Debian

```bash
# 官方脚本安装（推荐）
curl -fsSL https://get.docker.com | bash

# 将当前用户加入 docker 组（免 sudo）
sudo usermod -aG docker $USER

# 退出重新登录使权限生效，或执行：
newgrp docker

# 验证
docker --version
docker compose version
```

### 其他系统

- macOS：[Docker Desktop](https://www.docker.com/products/docker-desktop/)
- Windows：[Docker Desktop](https://www.docker.com/products/docker-desktop/) 或 WSL2 + 同上 Linux 步骤
- CentOS / Rocky：`dnf install docker-ce docker-compose-plugin`

git clone https://github.com/tonghaobo/betweenlines.git

## 三、配置 API Key

编辑 `docker-compose.yml`，只改一行：

```yaml
environment:
  - OPENAI_API_KEY=ark-你的实际Key    # ← 改这里
```

[火山引擎 ARK 控制台](https://console.volcengine.com/ark/region:ark+cn-beijing/overview) 获取 Key，格式 `ark-xxxxx`。

> 其余配置（模型名、端口、超时参数）已有默认值，无需修改。

---

## 四、构建镜像

```bash
docker build --network host -t betweenlines .
```

构建过程（约 2-5 分钟）：

```
Step 1/11  FROM ubuntu:24.04          → 使用本地已有镜像
Step 2-3   清除代理 + 系统环境配置
Step 4     apt 安装 Python3 + Node.js 20
Step 5     验证 node / python 版本
Step 6-7   复制项目文件
Step 8     后端：pip install 依赖
Step 9     前端：npm install + npm run build（生产构建）
Step 10-11 复制启动脚本 + 设置权限
```

> 若构建时 DNS 解析失败，确认用了 `--network host` 参数。

---

## 五、启动服务

```bash
docker compose up -d
```

5-10 秒后服务就绪。

## 七、外部访问

| 场景 | 地址 |
|------|------|

| 同网络其他设备 | `http://<服务器IP>:3000` |

## 八、常用运维命令

```bash
# 查看实时日志
docker logs -f betweenlines

# 停止
docker compose down

# 启动
docker compose up -d

# 重启（修改 docker-compose.yml 环境变量后）
docker compose up -d

# 完全重建（修改代码或 Dockerfile 后）
docker compose down
docker build --network host -t betweenlines .
docker compose up -d
```

## 九、数据

SQLite 数据库挂载在项目目录：

./data/betweenlines.db

## 十一、常见问题

### Q: 全新环境 `git clone` 后能直接用吗？

**A:** 能。Dockerfile / docker-compose.yml / entrypoint.sh / .dockerignore 都已提交 Git，克隆后改 API Key → 构建 → 启动，三步完成。

### Q: 构建时 `Temporary failure resolving`？

**A:** 加 `--network host`：`docker build --network host -t betweenlines .`

### Q: 启动后 API 500？

**A:** 检查 API Key：`docker exec betweenlines cat /app/backend/.env | grep OPENAI_API_KEY`

### Q: 截图分析失败？

**A:** 当前视觉模型配置为 `doubao-seed-1-8-251228`（已通过测试）。如果未来需要更换，修改 `docker-compose.yml` 中的 `VISION_MODELS` 后重启容器即可。

### Q: 容器重启会自动拉起服务吗？

**A:** 会。`entrypoint.sh` 自动启动前后端，`restart: unless-stopped` 保证宿主机重启后容器也自动启动。
