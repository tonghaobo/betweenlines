# 本地启动指南

## 环境要求

- **Node.js** 18+
- **Python** 3.11+
- **豆包 API Key**（火山引擎 ARK）

## 项目结构

```
chatvibe/
├── backend/           # FastAPI 后端（端口 8000）
│   ├── .env           # 后端环境变量（gitignore）
│   └── app/
│       ├── routers/   # API 路由
│       ├── services/  # 业务逻辑（OpenAI / Vision）
│       ├── schemas/   # Pydantic 数据模型
│       ├── middleware/ # 安全头、限流
│       └── core/      # 配置加载
├── frontend/          # Next.js 前端（端口 3000）
│   ├── .env.local     # 前端环境变量（gitignore）
│   └── src/
│       ├── app/       # 页面路由 & 布局
│       ├── components/# UI 组件
│       ├── contexts/  # React Context（i18n）
│       ├── locales/   # 国际化文案（zh / en）
│       └── lib/       # API 调用、Hooks
└── docs/              # 项目文档
```

## 一、后端启动

### 1. 进入后端目录 & 创建虚拟环境

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

> 如果遇到 `externally-managed-environment` 错误：
> - 确认已激活 `.venv` 虚拟环境（终端提示符前应有 `(.venv)`）
> - 如果 `.venv/bin/pip` 不存在，先执行 `python3 -m ensurepip --upgrade`

### 3. 配置环境变量

创建 `backend/.env` 文件：

```env
OPENAI_API_KEY=你的豆包API_Key（格式 ark-xxxxx）
OPENAI_MODEL=doubao-pro-32k
OPENAI_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
ALLOWED_ORIGINS=http://localhost:3000
```

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `OPENAI_API_KEY` | 豆包/火山引擎 API Key | **必填** |
| `OPENAI_MODEL` | 分析模型 | `doubao-pro-32k` |
| `OPENAI_BASE_URL` | API 地址 | `https://ark.cn-beijing.volces.com/api/v3` |
| `ALLOWED_ORIGINS` | CORS 允许的前端地址 | `http://localhost:3000` |

### 4. 启动服务

```bash
uvicorn app.main:app --reload --port 8000
```

- `--reload`：代码变更自动重启（开发用）
- `--port 8000`：监听端口

验证启动成功：

```bash
curl http://localhost:8000/health
# 返回 { "status": "healthy", ... }
```

### 5. 运行测试（可选）

```bash
python tests/test_api.py
```

## 二、前端启动

### 1. 进入前端目录 & 安装依赖

```bash
cd frontend
npm install
```

### 2. 配置环境变量

创建 `frontend/.env.local` 文件：

```env
NEXT_PUBLIC_API_URL=http://localhost:8000
```

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `NEXT_PUBLIC_API_URL` | 后端 API 地址 | `http://localhost:8000` |

### 3. 启动开发服务器

```bash
npm run dev
```

前端默认运行在 `http://localhost:3000`。

## 四、常见问题

### Q: 截图分析报错"分析失败"？

**A:** 检查 `backend/.env` 中的 `OPENAI_API_KEY` 是否正确。如果系统环境变量里也有 `OPENAI_API_KEY`（例如全局配了 OpenAI 的 Key），项目会优先使用 `.env` 文件的值（因为 `load_dotenv(override=True)`）。

验证方式：

```bash
cd backend
source .venv/bin/activate
python -c "from app.core.config import settings; print(settings.OPENAI_API_KEY[:20])"
# 应该输出 ark- 开头，不是 sk-proj- 开头
```

### Q: 前后端通讯不通？

**A:** 确认后端 CORS 配置中的 `ALLOWED_ORIGINS` 包含了前端地址（默认 `http://localhost:3000`）。

### Q: `pip install` 报 `externally-managed-environment`？

**A:** 你没有激活虚拟环境。执行 `source .venv/bin/activate` 后再试。

### Q: 前端修改了环境变量不生效？

**A:** Next.js 的 `NEXT_PUBLIC_*` 变量在构建时注入，修改后需要重启 `npm run dev`。
