# 项目概览

## 一句话定位

**BetweenLines（字里行间）**：帮用户分析聊天记录的氛围和状态，给出三种风格的回复建议，避免聊天翻车。

> "Understand the vibe before you reply."

---

## 技术栈

| 层级 | 技术 | 部署 |
|------|------|------|
| 前端 | Next.js 16 + React 19 + TypeScript + Tailwind CSS v4 | Vercel |
| 后端 | FastAPI + Python 3.11 + Pydantic v2 | Railway |
| AI | 豆包 API（火山引擎 ARK，OpenAI 兼容协议） | - |
| 存储 | SQLite（反馈、结果追踪和日志数据） | Railway Volume |

---

## 核心功能

| 功能 | 描述 |
|------|------|
| 统一输入 | 粘贴聊天文字 / 截图 / 图片，自动识别类型，无需选择模式 |
| 聊天分析 | 粘贴聊天记录 → AI 分析氛围/状态/风险 |
| 回复建议 | 三种风格（自然/幽默/成熟）的回复话术 |
| 节奏建议 | 回复时机和频率建议 |
| 截图 OCR | 上传聊天截图 → 前端压缩 → AI 提取文字 → 确认 → 分析 |
| 多图追加 | 提取文字后可继续添加截图，自动合并 |
| 反馈收集 | 👍/👎 + 原因多选 + 文本输入 |
| 回复采用率 | 采集用户是否使用了建议回复 |
| Follow-up 回访 | 24h 后追踪聊天后续结果 |
| 分享卡片 | 生成分析结果图片，一键复制到微信/小红书等 |
| 中英双语 | 完整的 i18n 支持（中/英） |
| 数据面板 | `/admin/metrics` 查看 DAU、留存率、有帮助率等指标 |

---

## 产品原则

| 规则 | 说明 |
|------|------|
| ❌ 不做绝对判断 | 不说"她喜欢你"等确定性结论 |
| ❌ 不代替用户聊天 | 不自动发送消息 |
| ❌ 不制造焦虑 | 禁止 PUA 风格，不恐吓用户 |
| ❌ 不训练模型 | V1 直接调用 API，不使用用户数据训练 |
| ✅ 聊天记录不存储 | 仅内存处理，不落盘 |
| ✅ 输出自然可发送 | 回复建议可直接复制使用 |

---

## 核心约束

- 输入限制：10 ~ 5000 字符
- 截图限制：PNG/JPEG/WebP，最大 10MB
- 速率限制：20 次/分钟（分析接口）
- 超时限制：分析 30s，截图 OCR 60s
